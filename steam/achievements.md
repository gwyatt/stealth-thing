# Steam achievements

Create these in Steamworks → *Stats & Achievements* using exactly these API names
(they are unlocked from `scripts/autoload/steam_service.gd`).

| API name | Display name | Description |
| --- | --- | --- |
| `FIRST_BLOOD` | First Flame | Win your first combat. |
| `WARDEN_FALLS` | Warden Falls | Defeat an elite. |
| `KING_DROWNED` | The King Drowns Again | Defeat the Drowned King. |
| `ROT_PURGED` | Purged | Defeat the Rot Colossus. |
| `TYRANT_FELLED` | The Flame Endures | Defeat the Ember Tyrant and win a run. |
| `LIGHTBRINGER` | Lightbringer | Reach maximum Light in a combat. |
| `PYROMANIAC` | Pyromaniac | Have 30 or more Burn on a single enemy. |
| `COLLECTOR` | Reliquary | Own 10 relics in a single run. |
| `MINIMALIST` | Minimalist | Win a run with 15 or fewer cards in your deck. |

Icons: use `assets/art/icons/*.png` as a starting point (64×64 JPG/PNG, plus a greyed "locked" variant).
